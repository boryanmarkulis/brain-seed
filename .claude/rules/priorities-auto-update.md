# Auto-Update Priorities

When a session produces a material change to the owner's priorities or income,
update `me/priorities.md` and `me/work.md` **immediately, in that same session**.
Do not defer it to `/reflect`. The point is that the rest of the current chat,
and every future session, sees the new reality right away.

## What counts as material

- A re-rank of what they are focused on, or a priority added or dropped.
- A real shift in income (rate, structure, client terms).
- A decided strategic shift that changes what the top priorities should be.

Not material: passing thoughts, maybes, routine progress on an existing
priority, brainstorming that did not land. When unsure, ask before writing.

## How to apply (respects the human-owned invariant)

`me/` is human-owned. Never rewrite it silently. Instead:

1. Draft the updated file or files in full, preserving format and voice.
2. Surface a single one-tap decision: show the meaningful before/after diff and
   ask "Apply to me/? (yes / no / edit)".
3. On yes, write immediately. On edit, apply the tweaks then write. On no, drop it.
4. If a decision was also made, make sure `decisions/log.md` has it (append-only).

One tap, no deferral. The owner should not have to think about keeping these
files current.

## No backstop

There is no nightly job that catches a missed priority shift later. The live
in-session confirm above is the only path. If you notice a material shift in a
session, surface it there and then.
